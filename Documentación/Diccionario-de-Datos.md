# Diccionario de Datos - Notificaciones

## 1. Visión General
Este diccionario de datos describe las entidades, campos, tipos de datos, restricciones y reglas de negocio de la base de datos relacional de la aplicación `TicketU`. El esquema está implementado en **PostgreSQL** usando **Supabase**

* **Manejo de Fechas:** Campos de tiempo en formato `Timestamptz` (Timestamp con zona horaria UTC).
* **Nomenclatura:** Nombres de tablas e índices en minúsculas

---

## 2. Catálogo de Tablas

### 2.1 Tabla: `auth_usuario`
* **Descripción:** Almacena los datos de identidad, roles, jerarquía y estado de seguridad de los usuarios del sistema.
Almacena los datos enviados por **Equipo Auth**, funciona de manera aislada del resto de tablas.


| Nombre del Campo | Tipo de Dato | Nulo / Obligatorio | Llave | Valor por Defecto | Descripción y Reglas de Negocio |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id_auth_evento` | `BIGINT` | **NOT NULL** | **PK** | `GENERATED BY DEFAULT AS IDENTITY` | Identificador único del evento de autenticación. |
| `tipo` | `TEXT` | **NOT NULL** | - | `RECUPERACION_PASSWORD` | Indica el tipo de Notificacion. |
| `id_usuario` | `TEXT` | **NULLABLE** | - | `NULL` | Identificador del usuario asociado al cambio de contraseña. |
| `email` | `TEXT` | **NOT NULL** | - | Ninguno | Correo electrónico asociado al usuario. |
| `url_recuperacion` | `TEXT` | **NULLABLE** | - | `NULL` | URL utilizada para la recuperación de contraseña. |
| `procesado` | `BOOLEAN` | **NOT NULL** | - | `FALSE` | Indica si el evento de autenticación fue procesado. |
| `error` | `TEXT` | **NULLABLE** | - | `NULL` | Información del error producido durante el procesamiento. |
| `created_at` | `TIMESTAMPTZ` | **NOT NULL** | - | `NOW()` | Fecha y hora de creación del evento de autenticacion. |
| `procesado_at` | `TIMESTAMPTZ` | **NULLABLE** | - | `NULL` | Fecha y hora en que el evento de autenticacion fue procesado. |

### 2.2 Tabla: `entradas_evento`
* **Descripción:** Almacena los datos enviados por el **Equipo Entradas** referentes a la compra de entradas e interactúa con **Equipo Panel** para el cancelamiento o cambio de fecha/hora de un evento.

| Nombre del Campo | Tipo de Dato | Nulo / Obligatorio | Llave | Valor por Defecto | Descripción y Reglas de Negocio |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id_entradas_usuario` | `BIGINT` | **NOT NULL** | **PK** | `GENERATED BY DEFAULT AS IDENTITY` | Identificador único de la entrada del usuario. |
| `id_usuario` | `TEXT` | **NULLABLE** | - | `NULL` | Identificador del usuario asociado a la entrada. |
| `id_evento` | `TEXT` | **NOT NULL** | - | Ninguno | Identificador del evento asociado a la entrada. |
| `nombre_comprador` | `TEXT` | **NOT NULL** | - | Ninguno | Nombre del comprador de la entrada. |
| `correo_comprador` | `TEXT` | **NOT NULL** | - | Ninguno | Correo electrónico del comprador. |
| `nombre_evento` | `TEXT` | **NOT NULL** | - | Ninguno | Nombre del evento asociado a la entrada. |
| `fecha_evento` | `TIMESTAMPTZ` | **NOT NULL** | - | Ninguno | Fecha y hora en que se realizará el evento. |
| `qr_data` | `TEXT` | **NULLABLE** | - | `NULL` | Datos asociados al código QR de la entrada. |
| `entrada_activa` | `BOOLEAN` | **NOT NULL** | - | `TRUE` | Indica si la entrada se encuentra activa. |
| `estado_evento` | `TEXT` | **NOT NULL** | - | `'PROGRAMADO'` | Estado del evento. Valores permitidos: `PROGRAMADO`, `CANCELADO`, `FINALIZADO`, `REPROGRAMADO`, `BORRADOR`. |
| `created_at` | `TIMESTAMPTZ` | **NOT NULL** | - | `NOW()` | Fecha y hora de creación del registro. |
| `updated_at` | `TIMESTAMPTZ` | **NOT NULL** | - | `NOW()` | Fecha y hora de última actualización del registro. |

### 2.3 Tabla: `notificacion`
* **Descripción:** Estructura de la notificación que será implementada en la app.

| Nombre del Campo | Tipo de Dato | Nulo / Obligatorio | Llave | Valor por Defecto | Descripción y Reglas de Negocio |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id_notificacion` | `BIGINT` | **NOT NULL** | **PK** |  `GENERATED BY DEFAULT AS IDENTITY` | Identificador único de la notificación. |
| `id_usuario` | `TEXT` | **NOT NULL** | - | Ninguno | Identificador del usuario que recibe la notificación. |
| `tipo` | `TEXT` | **NOT NULL** | - | Ninguno | Tipo de notificación. Valores permitidos: `COMPRA`, `RECORDATORIO`, `RECORDATORIO_24H`, `RECORDATORIO_30M`, `INICIO_EVENTO`, `EVENTO_CAMBIO`, `CAMBIO_EVENTO`, `CANCELACION_EVENTO`, `RECUPERACION_PASSWORD`, `CREACION_STAFF`. |
| `mensaje` | `TEXT` | **NOT NULL** | - | Ninguno | Mensaje que se mostrará al usuario. |
| `datos` | `JSONB` | **NOT NULL** | - | `'{}'::jsonb` | Datos adicionales asociados a la notificación. |
| `estado_lectura` | `TEXT` | **NOT NULL** | - | `'NO_LEIDA'` | Estado de lectura de la notificación. Valores permitidos: `NO_LEIDA`, `LEIDA`, `ELIMINADA`. |
| `fecha_lectura` | `TIMESTAMPTZ` | **NULLABLE** | - | `NULL` | Fecha y hora en que la notificación fue leída. |
| `fecha_eliminacion` | `TIMESTAMPTZ` | **NULLABLE** | - | `NULL` | Fecha y hora en que la notificación fue eliminada. |
| `created_at` | `TIMESTAMPTZ` | **NOT NULL** | - | `NOW()` | Fecha y hora de creación de la notificación. |

### 2.3 Tabla: `envios_notificacion`
* **Descripción:** Estructura de la notificación que será implementada en la app.

| Nombre del Campo | Tipo de Dato | Nulo / Obligatorio | Llave | Valor por Defecto | Descripción y Reglas de Negocio |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id_envio` | `BIGINT` | **NOT NULL** | **PK** | `GENERATED BY DEFAULT AS IDENTITY` | Identificador único del envío de notificación. |
| `id_notificacion` | `TEXT` | **NOT NULL** | **FK** | Ninguno | Identificador de la notificación asociada. Referencia a `notificacion(id_notificacion)`. |
| `usuarios_notificados` | `INTEGER` | **NOT NULL** | - | `0` | Cantidad de usuarios a los que se envió la notificación correctamente. |
| `usuarios_faltantes` | `INTEGER` | **NULLABLE** | - | `NULL` | Cantidad de usuarios a los que se les pudo enviar la notificación correctamente. |
| `canal` | `TEXT` | **NOT NULL** | - | Ninguno | Canal utilizado para el envío. Valores permitidos: `APP`, `EMAIL`. |
| `estado_envio` | `TEXT` | **NOT NULL** | - | Ninguno | Estado actual del envío: `PENDIENTE`, `ENVIADO`, `ERROR` |
| `intento` | `INTEGER` | **NOT NULL** | - | `1` | Número de intento de envío. |
| `error` | `TEXT` | **NULLABLE** | - | `NULL` | Información del error producido durante el envío. |
| `fecha_envio` | `TIMESTAMPTZ` | **NULLABLE** | - | `NULL` | Fecha y hora en que la notificación fue enviada. |
